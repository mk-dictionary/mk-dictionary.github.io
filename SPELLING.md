# SPELLING:

## Vowels

| spelling | english word example | konkani word example |
| -------- | -------------------- | -------------------- |
| a        | th**e**              | g**a**l              |
| aa       | f**a**ther           | m**a**zar            |
| e        | g**e**ntlem**e**n    | g**e**lee~           |
| ee       | **ai**lment          | gel**ee**~           |
| o        | **o**re**o**         | t**o**               |
| u        | r**oo**m             | t**u**               |

additionally, the tilde (~) is used to signal nasalized vowels

| konkani example |
| --------------- |
| haau~           |
| kite~           |
| bare~           |

This mimics standards of using a tilde (ã) to represent nasalization in other languages
